## 2.2 影视多平台版

### 2.2.1 PeekPro  

影视的二次开发版，最早版本PeekMill 外号羊壳，不支持TV。支持ios

项目地址  
[https://github.com/ingriddaleusag-dotcom/PickTV  ](https://github.com/ingriddaleusag-dotcom/PickTV    "PeekPro  官方")
