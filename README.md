基于  CatVod项目：  https://github.com/CatVodTVOfficial/CatVodTVJarLoader （已经删库）  
项目地址  
https://github.com/FongMi/TV  
软件下载地址（另外的仓库）  
https://github.com/FongMi/Release/tree/fongmi/apk  

mobile = 手机版  
leanback = 电视版  
arm64_v8a = 64 位  
armeabi_v7a = 32 位  

下载地址：  
https://github.com/FongMi/Release/raw/refs/heads/fongmi/apk/leanback-arm64_v8a.apk  

https://github.com/FongMi/Release/raw/refs/heads/fongmi/apk/leanback-armeabi_v7a.apk

2.4PeekPro  

影视的二次开发版，最早版本PeekMill 外号羊壳，不支持TV。支持ios  
功能很强，类似以前的猫影视。不兼容影视/Tvbox的接口  

项目地址  
https://github.com/ingriddaleusag-dotcom/PickTV  
下载（releases）  
https://github.com/ingriddaleusag-dotcom/PickTV/releases  


2.5TVbox  
基于  CatVod项目：  https://github.com/CatVodTVOfficial/TVBoxOSC （已经删库）  
目前的两个版本不支持一次导入多条线路。只能单条线路导入，只支持TV，没有手机版。  
分两个版本  
q版，白版（界面浅色）俊版  
https://github.com/q215613905/TVBoxOS
T版，黑版（界面深色）  
https://github.com/takagen99/Box  

下载项目地址（两个版本打包发布）  
https://github.com/o0HalfLife0o/TVBoxOSC  
下载（releases）  
https://github.com/j4Uq/TVBoxOSC/releases  


2.6影视仓  
不开源。作者安卓哥开发。支持一次导入多个不同地址的仓库。  



2.7FreeBox  
影视的二次开发版，支持PC，目前功能不是很完善。不兼容影视/Tvbox的接口  
项目地址  
https://github.com/kknifer7/FreeBox  
影视-K版  
https://github.com/kknifer7/TV-K  
影视-K版与 FreeBox 搭配使用的安卓端FongMi影视，详情请去 FreeBox 项目中查看。
